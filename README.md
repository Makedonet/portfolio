# Максим — разработка сайтов под ключ

Сайт-визитка с портфолио: кто я, какие сайты сделал, что входит в работу «под ключ» и как со мной связаться. Одна страница, статика, без клиентских библиотек.

![Главный экран](docs/preview-desktop.jpg)

## Технологии

- **Astro 7**: статическая генерация, на клиенте один маленький скрипт появления блоков
- **Tailwind CSS 4**: тема в `@theme` прямо в `src/styles/global.css`, без конфиг-файла
- **TypeScript**: данные и скрипт, `astro check` проходит без ошибок
- **Шрифты**: Onest и JetBrains Mono, self-host из `@fontsource-variable`, ни одного запроса к Google или CDN
- **Vercel**: статический хостинг

## Что внутри

| Блок | Реализация |
|------|-----------|
| Первый экран | Заголовок с маркером, который «дорисовывается» при загрузке; коллаж из трёх работ в рамках браузера и телефона |
| Цифры | Четыре замера из реальных проектов: вес страницы, PageSpeed, JS, мониторинг |

| Что входит | Девять услуг сеткой |
| Как работаю | Пять шагов: на телефоне столбцом, на широком экране строкой |
| Контакты | Телефон, Telegram и WhatsApp на один номер |

## Где что править

Всё содержимое лежит в `src/data/`, разметку для правок трогать не нужно.

- `site.ts`: имя, телефон, ссылки на мессенджеры, пункты меню
- `works.ts`: кейсы и демо. Каждая цифра там взята из README и аудитов самих проектов, источники перечислены в шапке файла
- `services.ts`: услуги и шаги работы

**Добавить работу:** положить скриншоты в `src/assets/works/` (десктоп 16:10, например 1440×900, и телефон 390×844) и дописать объект в `works` или `demos`. Astro сам нарежет AVIF и WebP под нужные ширины.

Для текстов из `data/` работает `src/lib/typo.ts`: он привязывает короткие предлоги к следующему слову и не даёт словам через дефис («Санкт-Петербург», «152-ФЗ») разорваться на конце строки.

## Производительность и доступность

Lighthouse, локальная сборка со сжатием brotli, по три прогона (24.10.2026):

| | Performance | Accessibility | Best Practices | SEO |
|---|---|---|---|---|
| Телефон | 98–99 | 100 | 100 | 100 |
| Компьютер | 100 | 100 | 100 | 100 |

На телефоне: LCP 2,0 с, CLS 0, вес страницы около 160 КиБ.

- axe-core: 0 нарушений на 390 и 1440 px
- Горизонтального переполнения нет на 375 / 390 / 768 / 1024 / 1440 px
- Фокус виден везде: чёрный контур с жёлтой подложкой, на тёмных блоках жёлтый
- Учитывается `prefers-reduced-motion`; без JavaScript страница видна целиком
- Контраст всех текстовых пар — WCAG AA и выше (пары перечислены в `global.css`)

## Разработка

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
npm run check    # проверка типов
```

Требуется Node.js 22.12 или новее. Astro закреплён на ветке 7.3: 7.4.2 требует Node 22.23.4.

## Выкладка

Репозиторий подключается к Vercel через **Add New → Project → Import**. Пресет Astro определяется сам (`vercel.json`), настраивать ничего не нужно.

Адрес для canonical, `og:url` и sitemap берётся из `VERCEL_PROJECT_PRODUCTION_URL`: это свой домен, если он подключён, иначе `*.vercel.app`. Задать адрес вручную можно переменной `SITE_URL`.
